# Sprint Quiz

> 매일 아침 8시, 내가 배운 내용으로 만든 복습 질문 한 개.

부트캠프에서 배운 AI/ML 내용을 오래 기억하기 위해 만드는 학습 리마인드 서비스입니다.
자료를 업로드해두면 AI가 질문과 모범 답안을 만들고, 매일 정해진 시간에 이메일 또는 디스코드로 보내줍니다.

<br>

## 왜 만들었나

부트캠프는 짧은 기간에 많은 내용을 학습합니다.

```
Python → 데이터 분석 → 머신러닝 → 딥러닝 → PyTorch → LLM/RAG → 서빙/배포
```

문제는 두 가지였습니다.

**1. 복습할 기회가 없다**
"수업 → 과제 → 다음 수업"으로 진도가 계속 밀려서, 지난 내용을 다시 떠올릴 일이 없습니다.

**2. 복습하려면 먼저 판단해야 한다**
ChatGPT에 물어보려면 "Docker에서 CMD와 ENTRYPOINT 차이 알려줘"처럼 *무엇을 복습해야 하는지 스스로 정해야* 합니다. 비전공자일수록 이 판단 자체가 어렵습니다.

Sprint Quiz는 그 판단과 행동을 서비스가 대신합니다. 사용자는 아침에 도착한 질문 하나를 보기만 하면 됩니다.

<br>

## 어떻게 동작하나

```
이메일 등록  또는  디스코드 연동
            ↓
           끝
```

이후 매일 오전 8시:

```
📚 오늘의 복습 질문

[범위] 딥러닝 / 활성화 함수

Q. ReLU에 대해서 설명해주세요.

[ 답변 확인하기 ]
```

`답변 확인하기`를 누르면 모범 답안이 나옵니다.
**답을 작성해서 제출하지 않습니다.** 머릿속으로 떠올려본 뒤 확인만 하는 구조로, 매일 쓰는 부담을 최소화했습니다.

<br>

## 설계 원칙

**질문은 아주 간단하게**
함정이나 응용을 묻지 않습니다. "오버피팅에 대해서 설명해주세요" 수준으로, 개념을 스스로 말로 풀어낼 수 있는지만 확인합니다. 목적이 변별이 아니라 리마인드이기 때문입니다.

**행동 부담 최소화**
가입은 한 번, 이후 매일 질문 하나. 접속할 사이트도, 제출할 답안도 없습니다.

**자료를 넣기만 하면 학습**
공부할 때마다 PDF나 ipynb를 올려두면 파싱부터 인덱싱까지 자동으로 처리됩니다.

## 아키텍처

```
        [학습 자료 업로드 (PDF / ipynb / md)]
                      │
                      ▼  (CI/CD 자동 트리거)
              Document Parser
                      │
                   Chunking
                      │
                  Embedding
                      │
                      ▼
          ┌───────────────────────┐
          │  PostgreSQL + pgvector │
          └───────────┬───────────┘
                      │
                      ▼
              RAG Retrieval  ◀── 오늘의 출제 범위
                      │
                      ▼
               Quiz Generator (LLM)
                      │
                      ▼
               Quiz Validator
                      │
              ┌───────┴────────┐
            Valid          Invalid → 재생성
              │
              ▼
        문제은행 저장 + 스케줄러 (매일 08:00)
              │
      ┌───────┴────────┐
      ▼                ▼
  디스코드봇        이메일 발송
```

## 기술 스택

| 영역 | 사용 기술 |
|---|---|
| Backend | Python, FastAPI |
| LLM | Anthropic Claude API |
| Database | PostgreSQL + pgvector |
| Scheduler | APScheduler |
| Notification | discord.py, Resend |
| Parsing | pymupdf, nbformat |
| Infra | Docker, Docker Compose |
