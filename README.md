# Sprint Quiz

> 매일 아침 8시, 내가 배운 내용으로 만든 복습 질문 한 개.

부트캠프에서 배운 AI/ML 내용을 오래 기억하기 위해 만드는 학습 리마인드 서비스입니다.
정리한 학습 노트를 넣어두면 AI가 질문과 모범 답안을 만들고, 매일 정해진 시간에 이메일 또는 디스코드로 보내줍니다.

<br>

## 왜 만들었나

부트캠프는 짧은 기간에 많은 내용을 학습합니다.

```
Python → 데이터 분석 → 머신러닝 → 딥러닝 → PyTorch → LLM/RAG → 서빙/배포
```

문제는 두 가지였습니다.

**1. 복습할 기회가 없다**
"수업 → 과제 → 다음 수업"으로 진도가 계속 밀려서, 지난 내용을 다시 떠올릴 일이 없습니다.

**2. 복습하려면 먼저 판단해야 한다**
ChatGPT에 물어보려면 "Docker에서 CMD와 ENTRYPOINT 차이 알려줘"처럼 *무엇을 복습해야 하는지 스스로 정해야* 합니다. 비전공자일수록 이 판단 자체가 어렵습니다.

Sprint Quiz는 그 판단과 행동을 서비스가 대신합니다. 사용자는 아침에 도착한 질문 하나를 보기만 하면 됩니다.

<br>

## 어떻게 동작하나

```
이메일 등록  또는  디스코드 연동
            ↓
           끝
```

이후 매일 오전 8시:

```
📚 오늘의 복습 질문

[범위] 딥러닝 / 활성화 함수

Q. ReLU에 대해서 설명해주세요.

[ 답변 확인하기 ]
```

`답변 확인하기`를 누르면 모범 답안이 나옵니다.
**답을 작성해서 제출하지 않습니다.** 머릿속으로 떠올려본 뒤 확인만 하는 구조로, 매일 쓰는 부담을 최소화했습니다.

<br>

## 설계 원칙

**질문은 아주 간단하게**
함정이나 응용을 묻지 않습니다. "오버피팅에 대해서 설명해주세요" 수준으로, 개념을 스스로 말로 풀어낼 수 있는지만 확인합니다. 목적이 변별이 아니라 리마인드이기 때문입니다.

**행동 부담 최소화**
가입은 한 번, 이후 매일 질문 하나. 접속할 사이트도, 제출할 답안도 없습니다.

**내가 정리한 것만 출제된다**
학습 자료는 Notion에 정리한 글을 Markdown으로 내보내 사용합니다. 정리했다는 것은 한 번 소화했다는 뜻이므로, 그 범위가 곧 복습 대상이 됩니다. 아직 안 배운 주제가 나오는 문제도 입력 단계에서 해결됩니다.

**키워드 단위로 출제한다**
글에서 AI 관련 키워드를 먼저 추출해 저장하고, 매일 아직 출제하지 않은 키워드 하나를 골라 질문을 만듭니다. 중복 출제 방지와 진도 파악이 구조적으로 해결됩니다.

<br>

## 동작 흐름

```
Notion 정리 글 → Markdown 내보내기 → data/
                      │
                      ▼
              마크다운 파일 읽기
                      │
                      ▼
            키워드 추출 (Claude API)
                      │
                      ▼
          ┌───────────────────────┐
          │  SQLite               │
          │   자료 / 키워드 /        │
          │   문제은행 / 호출 로그     │
          └───────────┬───────────┘
                      │
                      ▼
            미출제 키워드 1개 선택
                      │
                      ▼
             질문 생성 (Claude API)
                      │
                      ▼
                  Validator
                      │
              ┌───────┴────────┐
            통과            불합격 → 재생성
              │
              ▼
       문제은행 저장 (전날 밤 생성)
              │
              ▼
        스케줄러 (매일 08:00 발송)
              │
      ┌───────┴────────┐
      ▼                ▼
  디스코드봇        이메일 발송
```

<br>

## 사용법

Notion에서 정리한 글을 Markdown으로 내보내 `data/sample/`에 넣고 스크립트를 실행합니다.

```bash
# 자료·키워드만 등록
uv run python scripts/index.py --quiz 0

# 질문 5개까지 함께 생성 (기본값)
uv run python scripts/index.py

# 생성할 질문 개수 지정
uv run python scripts/index.py --quiz 10
```

이미 등록한 자료는 내용 해시로 걸러져 다시 처리되지 않습니다.

```
자료 파일 1개 발견
 [스킵] example.md - 이미 등록됨
질문 생성 (2개)
 HOG(Histogram of Oriented Gradients)에 대해서 설명해주세요.
 Convolution Filter(커널)에 대해서 설명해주세요.
========================================
신규 자료      0개
신규 키워드    0개
생성된 질문    2개
발송 대기      4개
========================================
```
